Rick and Morty Graphql APP

Rick and Morty / Explorer es una interfaz web moderna y minimalista diseñada para explorar el multiverso de la serie a través del API oficial de GraphQL. El objetivo principal de este proyecto es transformar una lista de datos convencional en una experiencia de usuario fluida, elegante y de alto rendimiento, aplicando patrones de diseño contemporáneos, microinteracciones cuidadas y una arquitectura de componentes escalable. Tech Stack & Architecture Core Framework: Angular 12 & TypeScript Data Layer: GraphQL & Apollo Client (queries optimizadas y manejo de estado de caché) Styling Engine: CSS3 Custom Properties nativas (Mobile-first, Flexbox/Grid, Dark Mode) UX Patterns: Command Palette (Ctrl + K), Skeleton Loaders & microinteracciones en CSS
