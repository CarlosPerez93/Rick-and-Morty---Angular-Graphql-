Rick and Morty Graphql APP

Rick and Morty / Explorer is a modern and minimalist web interface designed to explore the multiverse of the series through the official API from GraphQL. The main objective of this project is to transform one conventional data list in a smooth, elegant user experience and high performance, applying contemporary design patterns, careful microinteractions and a scalable component architecture. Tech Stack & Architecture Core Framework: Angular 12 & TypeScript Data Layer: GraphQL & Apollo Client (optimized queries and state management cache) Styling Engine: CSS3 Custom Native Properties (Mobile-first, Flexbox/Grid, Dark Mode) UX Patterns: Command Palette (Ctrl + K), Skeleton Loaders & microinteractions in CSS
